# AppForge

**Ambiente experimental de criação e edição de interfaces web.**

Repositório Next.js e React com ferramentas de edição de código, componentes visuais e empacotamento ZIP. O projeto integra o portfólio de pesquisa e desenvolvimento da W1 Capital; a presença dessas dependências não deve ser confundida com um construtor completo, implantado e pronto para uso comercial.

## Base técnica

| Camada | Tecnologia |
| --- | --- |
| Aplicação | Next.js 15 e React 19 |
| Edição | CodeMirror para JavaScript e CSS |
| Estado | Zustand |
| Interface | Tailwind CSS e Lucide |
| Arquivos | JSZip |
| Integrações exploratórias | Puter.js |

## Desenvolvimento local

```bash
npm install
npm run dev
```

Para gerar a compilação Next.js:

```bash
npm run build
npm run start
```

Os scripts seguem o `package.json` deste repositório. Não há distribuição desktop independente verificada.

## Distribuição no ecossistema

O AppForge permanece um projeto de desenvolvimento e **não possui executável Windows publicado**. Os aplicativos com instaladores verificáveis estão centralizados na [Central de Aplicativos W1 Capital](https://github.com/W1CAPITAL/Central-de-Apps).
